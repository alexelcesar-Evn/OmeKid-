# OmeKid

OmeKid es una app web responsive para llevar puntos positivos y negativos de conducta infantil durante la semana.

## Funciones

- Nombre del niño editable.
- Meta semanal editable.
- Tres premios semanales editables.
- Puntos positivos y negativos con razón.
- Progreso diario de lunes a domingo.
- Historial simple de la semana.
- Reinicio semanal.
- Guardado local en el navegador.

## Probar la app

Instala dependencias y levanta el servidor local:

```bash
npm install
npm run dev
```

Luego abre la URL que muestre Vite.
